# Personal site — V1

Minimal Astro personal site for Jesús Perales.

## Local development

```bash
npm install
npm run dev
```

## Vercel

Vercel should auto-detect Astro. Build command: `npm run build`. Output directory: `dist`.

## Before publishing

Replace the placeholder email in `src/pages/index.astro`:

```text
hello@example.com
```

with your real contact email.
